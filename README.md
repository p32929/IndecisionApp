# IndecisionApp

Can't decide what to do next? Add the things you are stuck between, tap **What should I do?**, and IndecisionApp picks one for you at random.

**Try it live:** https://p32929.github.io/IndecisionApp/

## Features

1. **Add your options,** remove one, or clear them all.
2. **One tap picks for you,** shown in a pop-up.
3. **Your list is saved** in the browser, so it is still there next time.

This was my first React app, built in 2019 while learning React. It uses plain class components and `react-modal`, with no state library. There is also a small counter app in `src/Playground/CounterApp/`.

## Run it

```bash
git clone https://github.com/p32929/IndecisionApp.git
cd IndecisionApp
npm install
npm start
```

Deploy to GitHub Pages:

```bash
npm run predeploy
npm run deploy
```
